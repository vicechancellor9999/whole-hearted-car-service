# 用户正式决策：车辆-客户关系口径（2026-08-10 07:45）

**决策人**：项目所有者（lijianfu），经 WorkBuddy 代为记录，即时生效。

## 决策内容

1. **保留关系历史**：车辆与客户的关系历史完整保留，带起止时间，任何历史关系不可删除或改写。
2. **一车一位当前客户**：每辆车同一时间最多一个 `endedAt = null` 的当前客户，允许暂时没有当前客户。
3. 换绑在同一原子保存中结束旧关系、建立新关系；旧工单、费用、照片、收付款归属保持原样，不回写历史客户。

## 与设计文档的关系

本决策与 `docs/superpowers/specs/2026-08-09-customer-vehicle-domain-design.md` 中"当前客户唯一性"及"既有 Mock 数据迁移"章节完全一致，视为对该口径的正式确认。此前"未确认前不固化"的前置条件自此解除，各 Agent 可按既定设计继续实现与验收，无需再等待确认。
