# apps/web 隔离参考边界

## 当前定位

- 本目录是隔离、非生产的视觉与交互参考，保存原 3210 高保真界面的外观、菜单、打印样式和操作方式。
- 本目录不是正式运行时，不是根 Next.js 16 应用的依赖，也不是正式 API、业务规则或验收结论的权威来源。
- 本目录不得进入正式 workspace、生产构建、CI、容器、部署清单或生产环境变量；根源码不得直接或间接 import 本目录。

## 当前权威入口

开发前按以下顺序读取根目录文件：

1. `../../docs/CONTINUATION_ENTRYPOINT.md`
2. `../../docs/superpowers/specs/2026-08-25-single-formal-repository-rescue-design.md`
3. `../../docs/superpowers/specs/2026-08-27-single-application-consolidation-design.md`

上述已批准设计和续接入口优先于本目录内的历史规格、交接材料和候选规则。本目录内关于业务规则与验收的材料仍属未批准候选或历史资料，不能据此裁定正式行为或验收通过。

## M1 使用方式

- M1 从本目录逐项复制或适配经过审核的设计 token、品牌资产、纯展示组件和交互行为到仓库根目录的 Next.js 16 应用。
- 迁移时以原 3210 界面作为视觉与交互参照，同时以根应用的正式 DTO、服务端会话、权限和 PostgreSQL 边界重新接入数据。
- 不把 Next.js 14 运行结构、Mock 回落、业务 localStorage、客户端身份、客户端密钥、旧 API 适配层或本目录测试配置带入正式运行路径。
- 每次取用参考资产前先建立只读差异与归属清单，保留来源说明并验证迁入根应用后的真实行为。
