# Business Order 单据英文版与预览缩放设计

## 目标

客户联和办公室签字留底联在同一个冻结版本下同时保存中文版与纯英文版 PDF；维修工联只保存中文版。单据页面默认把整张 A4 适配到可视宽度，并提供明确的缩放控制。

## 正式文件边界

- 每个客户联、办公室留底联修订版同时拥有 `zh` 与 `en` 两个 PDF 文件、文件哈希和鉴权下载入口。
- 维修工联只有 `zh` 文件；界面不显示语言切换。
- 中英文文件共享单据编号、修订号、业务快照、金额和生成时间，只改变模板标签及已有的中英文字段选择。
- 英文渲染不得输出中文模板标签。收费项目名称、说明、单位、备注和支付方式缺少英文时，生成修订版前返回可理解的缺失字段错误，不保存不完整文件。
- 现有修订版通过新的渲染器版本追加修订并生成中英文文件；旧文件和旧哈希继续保持不可变。

## PDF 模板

- `zh` 沿用现有中文主标题和中英辅助信息。
- `en` 只显示英文模板标题、字段名、章节名、类别、付款类型、确认文字和签字标签；姓名、车牌、VIN、单据编号等业务原值保持原样。
- 下载文件名分别以 `-ZH.pdf`、`-EN.pdf` 结尾。

## 页面交互

- 客户联和办公室留底联显示 `中文 / English` 分段切换，切换后重新读取对应正式文件。
- 当前语言决定预览、下载和系统打印的文件；切换不创建新业务修订。
- 预览工具栏提供缩小、当前百分比、放大、`适合宽度` 和 `100%`。
- 默认和容器尺寸变化时使用适合宽度；手动缩放范围为 50%–200%，步进 10%。放大后只在预览内部横向滚动。
- Retina 清晰渲染继续使用 `devicePixelRatio`，缩放只改变 PDF viewport 的 CSS 尺寸，不降低像素密度。

## 验收

- 三种中文文件与两种英文文件均为真实 A4 PDF，下载字节与预览、打印字节一致。
- 英文文件全文无中文字符；现有客户联、办公室留底联英文版可生成并读取。
- 默认预览完整显示 A4 左右边缘；50%、100%、200% 与适合宽度均可切换。
- 文件读取继续要求正式会话和原有角色权限；无效语言返回 400。
