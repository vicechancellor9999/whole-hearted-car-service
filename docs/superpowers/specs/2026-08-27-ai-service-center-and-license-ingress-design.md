# Whole Hearted AI 服务中心与驾驶证识别设计

状态：用户已确认实施

日期：2026-08-27
时区：America/Jamaica

## 1. 目标

将现有分散的 DeepSeek 文本设置和 OpenAI / Google 证件识别设置合并为一个“AI 服务中心”。管理员只在一个页面管理服务商、密钥、模型、任务顺序与自动切换。文本拆单、客户驾驶证和车辆证件各自拥有独立调用顺序；首选服务不可用时自动尝试下一项。

客户驾驶证入口同时支持点击、拍摄、拖拽和粘贴图片。识别结果始终进入人工确认界面，不直接覆盖客户正式资料。

## 2. 服务商与任务路由

首期支持四类服务商：

- DeepSeek：OpenAI-compatible 文本接口；
- OpenAI：文本与视觉识别；
- Google Vision：证件 OCR；
- 自定义兼容服务：由管理员设置 HTTPS API 地址、密钥和模型。

系统按任务保存独立有序路线：

- 文本处理：拆单、自动修复、翻译辅助；
- 客户驾驶证：驾驶证正面字段识别；
- 车辆证件：车辆证件字段识别。

每条路线由启用开关、自动切换开关和若干 `{服务商, 模型}` 步骤组成。每次调用最多尝试路线中的每个步骤一次，不循环重试同一服务商。

## 3. 自动切换规则

下列情况允许尝试路线下一项：

- 未配置或已停用；
- 配额耗尽、HTTP 429；
- 网络错误或超时；
- HTTP 5xx；
- 密钥失效或无权限；
- 返回空内容、无法解析或不满足当前任务最低字段要求。

用户主动取消以及明确的输入格式错误不触发无意义的重试。所有服务都失败时返回可理解的业务错误，同时保留驾驶证手工填写入口。

系统仅记录任务、时间、服务商、模型、结果类别与切换原因；不记录 API Key、图片、客户资料、提示词或模型原文。

## 4. 密钥与配置保护

- API Key 只保存于服务器运行目录的权限文件，浏览器只能收到掩码；
- 设置接口只允许 `super_admin` 访问和修改；
- 写入使用临时文件、原子替换和 `0600` 权限；
- 旧服务器证件识别配置自动迁移并保留当前密钥与模型；
- 浏览器旧 DeepSeek 设置仅在服务器尚无 DeepSeek 密钥时迁移，服务器确认保存后才清除浏览器明文；失败则保留原值并提示；
- 自定义兼容地址必须为 HTTPS，不能包含用户名、密码、查询参数、片段，也不能指向本机或私网字面地址。

## 5. 驾驶证图片入口

入口支持：

- 点击选择文件；
- 移动设备调用后置摄像头；
- 将一张 JPEG / PNG 拖入区域；
- 在焦点不处于输入框、文本域、下拉框或可编辑区域时粘贴一张图片。

一次提供多张图片时不静默选取，直接提示“一次只能添加一张驾驶证正面”。图片大小上限 12 MB。拖拽进入时显示明确高亮，选中后继续沿用现有裁切、旋转、预览和手工校对流程。

## 6. 识别增强

服务端在识别前自动校正方向、应用裁切和旋转、适度标准化与锐化，并控制输出尺寸。识别提示针对牙买加驾驶证字段，要求结构化输出姓名、出生日期、性别和地址。

完整字段通过后停止；部分字段被保留为候选，并继续尝试下一服务。若全部服务都只返回部分结果，选取字段最完整的一份返回人工校对，不跨服务拼接互相冲突的个人资料。

识别结果必须标记待人工确认。缺少驾驶证或识别不完整属于 `待补` / `待验证`，不阻止客户建档。

## 7. 设置页面

设置页保留 Whole Hearted 现有浅色、圆角、蓝色主操作语言，采用 IBM Carbon 的信息层级原则组织为一个 AI 服务中心：

1. 总览：可用服务数量、三类任务状态、最近一次切换；
2. 服务商：启停、密钥掩码、模型、自定义地址、保存与连接测试；
3. 任务路线：按任务调整服务商和模型顺序，并设置自动切换；
4. 最近事件：仅展示安全元数据和可处理原因。

桌面采用清晰分区，窄屏退化为单列；交互目标不小于 44 px。状态色只表达可用、提醒和错误，不增加装饰性营销区块。

## 8. 接口兼容

- 新增统一的服务器 AI 设置与执行模块；
- 文本 `/api/ai/chat` 不再接收浏览器传来的 API Key，改用服务器任务路线，并要求正式会话；
- 客户驾驶证与车辆证件复用统一自动切换执行器；
- 旧车辆证件设置接口在迁移期保持兼容，但新设置页只使用统一接口；
- 现有业务调用合同尽量保持不变，新增的服务商与切换元数据不要求页面消费者处理。

## 9. 验收

必须同时满足：

1. 旧证件配置和旧 DeepSeek 配置迁移不丢密钥；
2. 普通用户无法读取或修改 AI 设置，响应中不出现明文密钥；
3. 三类任务均可按配置顺序自动切换，日志不含客户资料与密钥；
4. 驾驶证点击、拖拽、粘贴、超限、多图和输入框粘贴保护均有测试；
5. 驾驶证首选失败或结果不足时可尝试后备服务，并返回最佳可校对结果；
6. 设置保存、刷新、连接测试和重新排序可用；
7. 单元测试、协作检查、类型检查、生产构建和页面浏览器验收通过；
8. 全部工作只发生在 3220 候选工作区，不修改 3210 / 3211 与正式数据库。
