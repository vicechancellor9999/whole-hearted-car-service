# 阶段 5：Business Order 办公室留底联与维修工联验收清单

验收对象：Whole Hearted 正式系统，PC 网页端。

验收原则：正式生成的打印件是不可修改快照。后来编辑收费项目、增加收款或退款，只改变当前 Business Order，不得改写已经生成的办公室留底联或维修工联。需要反映当前事实时，重新生成一份新编号打印件。

## 一、验收前准备

- [ ] PostgreSQL 测试库已启动，`0015_business_order_documents.sql` 已完成迁移。
- [ ] 已按 `.env.example` 配置本地测试环境变量，`http://127.0.0.1:3211/api/health` 返回 `ready`。
- [ ] 已创建超级管理员、前台、老板只读三个测试账号。
- [ ] 准备一张包含车辆、VIN、维修轮次、维修班组和收费项目的 Business Order。
- [ ] 收费项目同时包含工时、配件、其他费用、本项折扣、工时折扣、配件折扣、其他费用折扣、整单折扣和备注。
- [ ] Business Order 至少已有一笔收款，便于核对办公室联的收付款历史和余额。

## 二、生成入口与文档历史

- [ ] 以超级管理员打开 Business Order 详情页。
- [ ] 在同页“正式打印件”区域确认存在“生成办公室留底联”和“生成维修工联”。
- [ ] 点击“生成办公室留底联”，确认跳转至新文档，并记录 `OFF-YYYYMMDD-0001` 格式编号。
- [ ] 返回详情页，点击“生成维修工联”，确认跳转至新文档，并记录 `MEC-YYYYMMDD-0001` 格式编号。
- [ ] 返回详情页，确认文档历史同时列出两份打印件、生成时间、生成人和“打开 / 补打”入口。
- [ ] 再次点击历史中的“打开 / 补打”，确认沿用原文档编号，不产生新编号。

## 三、办公室留底联内容

- [ ] 标题、中英文公司信息、Business Order 编号、费用承担方、联系人、TRN、车辆、VIN 和生成时间正确。
- [ ] 收费项目按工时、配件、其他费用分开显示。
- [ ] 每项显示项目名称、描述、单位、数量、含税单价、本项折扣和折后小计。
- [ ] 汇总区分别显示本项折扣、工时折扣、配件折扣、其他费用折扣和整单折扣。
- [ ] 显示折后应收总额和其中所含 15% GCT，不把 GCT 当成可以折扣的独立收费项目。
- [ ] 收付款历史逐笔显示发生时间、编号、方式和金额；累计收款、累计退款、未结余额正确。
- [ ] 客户诉求、工作说明、责任义务与提前告知、办公室内部备注均完整显示。
- [ ] 客户认可声明、中英文客户签字线和日期线完整显示。

## 四、维修工联内容与脱敏

- [ ] 维修工联正文为中文，允许保留业务全称 `Business Order` 和车辆标准字段 `VIN`。
- [ ] 显示 Business Order 编号、车辆、VIN、维修轮次、维修班组和打印时间。
- [ ] 显示施工项目的中文名称、中文描述、单位、数量，以及施工相关备注和提前告知。
- [ ] 显示回单工作内容、实际维修工、完成时间和维修工签名填写区。
- [ ] 页面不显示客户姓名、联系人、电话、TRN。
- [ ] 页面不显示含税单价、折扣、小计、总额、收付款、余额或绩效。
- [ ] 页面不显示办公室内部备注。

## 五、快照不可修改与重新生成

- [ ] 记录第一份办公室留底联的收费版本、应收、收付款历史和余额。
- [ ] 返回 Business Order，编辑一项收费价格或折扣并保存新收费版本。
- [ ] 再登记一笔独立收款，生成对应 Receipt。
- [ ] 补打第一份办公室留底联，确认收费版本、应收、收付款历史和余额仍与第一次生成时完全一致。
- [ ] 补打第一份维修工联，确认原维修轮次、班组、施工项目和备注没有变化。
- [ ] 再生成一份办公室留底联，确认获得新编号，并反映当前收费版本和新增收款。
- [ ] 直接尝试修改或删除 `business_order_document_snapshots` 记录，确认数据库拒绝。

## 六、角色权限

- [ ] 超级管理员可以生成、查看和补打两类打印件。
- [ ] 前台可以生成、查看和补打两类打印件。
- [ ] 老板只读账号可以查看和补打历史打印件。
- [ ] 老板只读账号看不到生成按钮；直接调用生成操作时也被服务端拒绝。

## 七、打印布局

- [ ] 办公室留底联点击“打印 / Print”，A4 预览不显示系统导航、返回链接或打印按钮。
- [ ] 维修工联点击“打印”，A4 预览不显示系统导航、返回链接或打印按钮。
- [ ] 两种打印件在常用桌面宽度没有横向滚动条、内容截断或文字重叠。
- [ ] 多页打印时标题、项目、备注、签字区和页脚顺序清晰，不出现表格行被异常切断。
